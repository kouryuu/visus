# visus icon

The bionic eye uses electric blue neon tubes, both circuit leads, and a simple iris. Its interior and background stay transparent, with a soft glow around the strokes.

- [SVG source](visus-icon.svg): the explorer header, browser favicon, and README mark.
- [Neon PNG](../../../../apps/vscode/icon.png): the VS Code extension icon.

The PNG was refined from the SVG with the built-in imagegen tool.

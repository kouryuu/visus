# Change story

Read only the matching skill, then its shared authoring reference:

- A pull request: [visus-pr](../visus-pr/SKILL.md).
- Current local changes or an explicit comparison: [visus-on-demand](../visus-on-demand/SKILL.md).
- A visus hook requests repair, or the user requests hook setup: [visus-hook](../visus-hook/SKILL.md).

For a general request to generate a review, use on-demand. These workflows create local drafts and published JSON revisions; visus does not publish to a hosting service. Stories are agent-authored explanations, not independent verification.
